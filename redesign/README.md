# Clon visual azul de TrendPulseShop

Versión independiente en `/redesign/`. No sustituye la portada original.

- HTML, CSS y JavaScript sin dependencias.
- Catálogo tomado de index.html: referencia 13/10/2026, no actualizado en tiempo real.
- Conserva el identificador de afiliado trendpulsesho-21.
- Buscador, categorías, paginación y modo oscuro local.
- Hero generado con IA; las tarjetas usan imágenes ilustrativas de categorías del proyecto o un símbolo neutral cuando no hay imagen. No representan el producto exacto.
- No muestra precios ni valoraciones sin verificar.
- Incluido en la compilación Netlify existente; ruta final tras desplegar: /redesign/.
- Se excluye de indexación durante revisión mediante meta robots noindex.

Para verlo en local desde la raíz del repositorio: `python3 -m http.server 8080`, abrir http://localhost:8080/redesign/.

La integración con el servidor Minotauro no se ha realizado: este clon no requiere un servicio de IA en ejecución. No contiene claves ni direcciones de servidor.
