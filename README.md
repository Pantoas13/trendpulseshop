# TrendPulseShop

Lo más vendido en Amazon.es, por categorías, con guías de regalos y rankings que se actualizan cada día.
Web: https://pantoas13.github.io/trendpulseshop/

## Dónde está cada cosa

| Carpeta o archivo | Qué es |
|---|---|
| `index.html`, `redesign/` | Portada y catálogo |
| `regalos-*.html`, `mejores-*.html`, `guias.html` | Guías de compra y de regalos |
| `top/` | Rankings por categoría (se rehacen cada día) |
| `marca/` | Sistema de diseño común a todas las páginas (letras, colores, botones, tarjetas): ver `marca/DISENO.md` |
| `geo-amazon.js` | Lleva a cada visitante a la Amazon de su país |
| `pins/`, `promo/`, `reels/`, `img/` | Imágenes y vídeos de promoción |
| `scripts/` | Programas que generan páginas y pines |
| `mayordomo/` | Diario del programa diario (`LEEME.md` explica cómo funciona) |
| `motor/`, `mayoristas/`, `imperio/`, `flippulse/`, `minotauro/` | Otros proyectos publicados |
| `.github/workflows/` | Tareas automáticas |

Los archivos publicados no se mueven de sitio: los enlaces ya compartidos dejarían de funcionar.

Como afiliado de Amazon, obtenemos ingresos por las compras adscritas que cumplen los requisitos aplicables.
